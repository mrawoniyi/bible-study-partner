# State note — the chat-app variant

Use this when your harness has no filesystem: a chat-app project, a custom GPT-style assistant, or
anything where the partner cannot write files. All of `state/` collapses into this one note. You
keep it somewhere you can paste from (a notes app, a pinned message, the project's own notes field),
paste it at the start of a session, and paste the updated version back at the end.

What you lose by doing it this way: nothing resumes by itself, and long-term feed-forward across
programmes only works as far back as what you keep pasting. See the harness table in the README.

Copy everything between the lines.

---

```
BIBLE STUDY — STATE NOTE
Last updated: <YYYY-MM-DD>

## SETTINGS
Name: <name>
Translation: NIV
Tiers: quick 5-10 / standard 15-20 / deep 30+
Journal: note (kept in this file, under JOURNAL below)

## PROFILE
Where I am now: <...>
How I relate to God: <...>
Prayer life: <...>
Formative experiences: <...>
What I wrestle with: <...>
What I want to shift: <...>
How I like to engage: <...>

## PLAN
Concept: <title>
Length: <N> days
Status: active
Current day: <N>
Days:
- Day 0: <title> — <synopsis> [full]
- Day 1: <title> — <synopsis> [outline]
- ...

## DAY <N> (full content, generated at the end of the previous session)
Opening reflection: <...>
Passages: <citations>
Reflection from my journey: <...>
Questions:
1. [Personal Connection] <...>
2. [Tension] <...>
Prayer prompts: begin / practice / close — <...>

## SESSIONS SO FAR
Day 0 (<date>, standard)
  Insights: <insight> (high); <insight> (med)
  Patterns: <pattern> (Day 0)
  Commitments: [start] <...>
Day 1 (<date>, quick)
  Insights: ...

## JOURNAL
### <YYYY-MM-DD> — <title> (Daily Devotion)
<verbatim answers under their question headings>

### <YYYY-MM-DD> — <title> (Reflections)
<verbatim reflection>
```

---

**How to use it in a session.** Paste the note. Say "let's study". At the end, say "I'm done with
Day N" and ask for the updated state note back; the partner returns the whole block with the new
session added, the next day generated in full, and the current day bumped. Replace your saved copy
with it.

**Keep it trimmed.** If the note gets long, keep the full text of only the current day and the last
three sessions' insights, and let older journal entries live wherever you normally keep notes.
