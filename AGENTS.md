# Agent instructions

Read `SKILL.md` in this folder and follow it. It is the whole engine; there is no code to run.

State lives in plain files beside it: `settings.md`, `profile.md`, `state/` (the plan pointer, plans
and sessions) and `journal/` (one file per completed session, reflection or import). Read them
before acting and write them as `SKILL.md` instructs.

If `profile.md` does not exist, start with the Onboarding procedure.

Nothing here talks to a server. Everything stays on this machine.
